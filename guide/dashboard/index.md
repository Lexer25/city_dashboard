# Модуль dashboard — панель "Артонит Сити"

## Назначение

Модуль **dashboard** предназначен для контроля состояния работы комплекса СКУД Артонит Сити.  
## Вызов панели управления
Нажмите на пункт меню "Артонит Сити Центр".

### Что предоставляет модуль dashboard:  

Информация сгруппирована в блоки:  
Информация по сотрудника
Оборудование
Очередь загрузок
system
анализ события за последние 24 часа.

## Блоки информации

| Блок информации | Описание | Где используется |
|------------------|----------|------------------|
| **Информация по сотрудникам** | Данные о сотрудника, картах, просроченных и неактивных картах, сроках действия. | `dashboard`<br>`skud`<br>`people` |
| **Оборудование** | Данные о транспортных серверах и контроллерах | `dashboard`<br>`skud`<br>`device_panel` |
| **Очередь загрузок** | Состояние очереди загрузки.. | `dashboard`<br>`load_order`<br>`device_panel` |
| **System** | Параметры настроек системы, количество событий в базе данных СКУД. | `dashboard`<br>`system` |
| **Анализ событий за последние 24 часа** | Аналитика событий проходов и отказов за сутки. Включает коды аналитики, описание нарушений, количество событий, выявление ошибочных отказов, определение режима ТЕСТ у контроллеров. | `dashboard`<br>`analit`<br>`event_panel` |

## Порядок работы
**Срок карты закончился**. Должен быть 0. При штатной работе эта цифра должна  быть 0. Если не 0, то клик по цифре показет спиоск сотрудников, у которых закончился срок действия карты.  
**Количество неактивных карт**. Должен быть 0.Это количество необходимо контролировать. Неактивные карты хранятся в базе данных с историей и занимеют место. Если карту не планируют сделать активной, то ее лучше удалить.  
**Неправильный формат RFID**. Должен быть 0.Показывает номера идентификаторов RFID, формат которых не совпадает с настройками. Необходимо проверить идентификаторы с неправильными номерами, изменить их.

## Результат анализа событий за последние 24 часа
Выводится статистика по событиям за послендние 24 часа с указанием кодов аналитики.
